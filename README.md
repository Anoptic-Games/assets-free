# assets-free

Freely redistributable assets for the Anoptic game engine.

Everything here is licensed **CC BY 4.0**
(<https://creativecommons.org/licenses/by/4.0/>).

You may use, modify, and redistribute these assets — including commercially —
**provided you give appropriate credit.** Attribution is a condition of the
license, not a courtesy.

Per-asset credits are in [`ATTRIBUTION.md`](ATTRIBUTION.md). Keep them with the
files if you redistribute them.

The third-party assets retain their original CC BY 4.0 terms. `cursed.png` is
an original Anoptic Games texture, also released under CC BY 4.0.
